# VOID / Adler Zero — Writings

A minimal Model K index for arguments on Socionics, logic, and epistemology.

## Included

- Prose version of *Identity of the Object, Not Identity of the Theory* on its own reading page
- Local formal / mathematical version with MathJax rendering
- Local page for *An Axiomatic Approach to the Elements of Socionics*
- Local page for *Axiomatic Socionics — Analytic Notes*

The design uses a two-color `#353535` / `#e0e0e0` palette, editorial typography, staggered entrance motion, and responsive navigation interactions.

## GitHub Pages

The included GitHub Actions workflow deploys the static site to GitHub Pages on every push to `main`.
